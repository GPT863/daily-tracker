# 日常活动记录器

一个轻量的个人健康生活记录应用，帮助您记录每天的饮食、用药、运动、睡眠和感受。

## ✨ 功能特点

- 📅 **时间线展示** - 直观查看一天的所有活动
- 🍽️ **多种活动类型** - 用餐、用药、运动、睡眠、工作等
- 💭 **感受记录** - 记录每个活动后的心情和感受
- ⏱️ **时长追踪** - 记录活动持续时间
- 📊 **数据统计** - 自动统计用餐次数、活动总数等
- 📤 **数据导出** - 支持JSON和CSV格式导出
- 💾 **本地存储** - 数据存储在浏览器本地，保护隐私
- 📱 **PWA支持** - 可添加到主屏幕，具备基础安装能力

## 🚀 如何使用

### 方法1：直接在浏览器中打开

1. 下载所有文件到同一目录
2. 用浏览器打开 `index.html`
3. 开始记录你的活动！

### 方法2：本地服务器运行

```bash
# 使用Python启动简单服务器
python -m http.server 8000

# 或使用Node.js的http-server
npx http-server

# 然后在浏览器访问
# http://localhost:8000
```

### 方法3：部署到服务器

可以部署到以下平台：
- GitHub Pages
- Netlify
- Vercel
- 任何静态网站托管服务

## 📱 添加到主屏幕（PWA）

1. 在浏览器中打开应用
2. 点击浏览器的"分享"按钮
3. 选择"添加到主屏幕"
4. 现在可以像原生应用一样使用了！

## 💾 数据存储

所有数据都存储在浏览器的LocalStorage中，具有以下特点：

- ✅ 完全本地化，保护隐私
- ✅ 数据保存在本地浏览器中
- ✅ 永久保存（除非清除浏览器数据）
- ⚠️ 更换浏览器或清除缓存会丢失数据

**建议：定期导出数据备份！**

## 📤 数据导出

支持两种导出格式：

- **JSON** - 导出当前所选日期的活动数据
- **CSV** - 适合在Excel等软件中打开和分析

## 🎨 活动类型

- 🍽️ 用餐 - 记录早餐、午餐、晚餐等
- 💊 用药 - 记录服药、补充剂等
- 🏃 运动 - 健身、跑步、运动等
- 😴 睡眠 - 睡觉、午休、补觉等
- 💼 工作 - 工作相关活动
- 📌 其他 - 任何其他活动

## ⌨️ 快捷键

- `Ctrl + N` - 添加新活动
- `Esc` - 关闭模态框

## 🔧 技术栈

- 纯HTML5 + CSS3 + JavaScript
- LocalStorage 数据存储
- PWA（渐进式Web应用）
- 响应式设计，支持移动端
