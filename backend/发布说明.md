## 🚀 快速部署步骤

### 方案一：本地测试

1. **解压发布包到目标目录**
   ```
   解压到: C:\DailyTracker\Api\
   ```

2. **运行服务**
   ```batch
   # 方式1: 双击启动脚本
   双击 start.bat

   # 方式2: 直接运行
   双击 DailyTracker.Api.exe

   # 方式3: 命令行
   cd C:\DailyTracker\Api
   DailyTracker.Api.exe
   ```

3. **验证服务**
   ```batch
   # 打开浏览器访问
   http://localhost:8080/health
   ```

### 方案二：部署到云服务器

#### Windows 上传到 Linux

1. **使用 WinSCP 或 FileZilla 上传**
   - 连接: `root@your-server-ip`
   - 上传: `DailyTracker.Backend.Release.20260313.zip` 到 `/opt`

2. **SSH 登录服务器**
   ```bash
   ssh root@your-server-ip
   ```

3. **解压并部署**
   ```bash
   cd /opt
   unzip DailyTracker.Backend.Release.20260313.zip -d daily-tracker-api
   cd daily-tracker-api
   chmod +x start.sh stop.sh

   # 安装 .NET 8 运行时（如果未安装）
   # Ubuntu/Debian:
   apt-get install aspnetcore-runtime-8.0

   # CentOS/RHEL:
   yum install aspnetcore-runtime-8.0

   # 启动服务
   ./start.sh
   ```

4. **配置防火墙**
   ```bash
   # CentOS/RHEL
   firewall-cmd --permanent --add-port=8080/tcp
   firewall-cmd --reload

   # Ubuntu
   ufw allow 8080/tcp
   ```

5. **配置云服务商安全组**
   - 在阿里云/腾讯云控制台
   - 添加入站规则: 端口 8080，协议 TCP，来源 0.0.0.0/0

6. **验证服务**
   ```bash
   curl http://localhost:8080/health

   # 从本地电脑测试
   curl http://your-server-ip:8080/health
   ```

#### 配置为系统服务（可选）

```bash
# 创建 systemd 服务
sudo nano /etc/systemd/system/daily-tracker-api.service
```

复制以下内容：
```ini
[Unit]
Description=DailyTracker Backend API
After=network.target

[Service]
Type=notify
WorkingDirectory=/opt/daily-tracker-api
ExecStart=/usr/bin/dotnet /opt/daily-tracker-api/DailyTracker.Api.dll --urls "http://0.0.0.0:8080"
Restart=always
RestartSec=10
SyslogIdentifier=daily-tracker-api
User=root
Environment=ASPNETCORE_ENVIRONMENT=Production

[Install]
WantedBy=multi-user.target
```

启动服务：
```bash
sudo systemctl daemon-reload
sudo systemctl enable daily-tracker-api
sudo systemctl start daily-tracker-api
sudo systemctl status daily-tracker-api
```

### JWT 密钥（⚠️ 需要修改）

**重要！** 生产环境请务必修改 JWT 密钥：

1. **生成随机密钥**
   ```bash
   # Linux
   openssl rand -base64 32

   # Windows PowerShell
   -join ((48..57) + (65..90) + (97..122) | Get-Random -Count 32 | % {[char]$_})
   ```

2. **修改配置文件**
   - 编辑: `appsettings.Production.json`
   - 修改: `Auth:SigningKey` 字段为生成的随机密钥

3. **重启服务**
   ```bash
   systemctl restart daily-tracker-api
   ```

## ❓ 常见问题

### 1. 服务启动失败

**检查 .NET 运行时**
```bash
dotnet --info
```

**查看日志**
```bash
# Linux
journalctl -u daily-tracker-api -n 50

# Windows
查看控制台输出
```

### 2. 数据库连接失败

**测试连接**
```bash
mysql -h usw-cynosdbmysql-grp-mav8vmwf.sql.tencentcdb.com -P 20741 -u root -p
```

**检查项**
- 云数据库安全组是否允许服务器IP
- 用户名密码是否正确
- 数据库是否已创建

### 3. 无法从外部访问

**检查清单**
- ✅ 服务是否正常运行
- ✅ 防火墙是否开放 8080 端口
- ✅ 云服务商安全组是否配置
- ✅ 服务器内部是否可访问: `curl http://localhost:8080/health`
